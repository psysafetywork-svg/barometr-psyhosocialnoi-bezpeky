# Барометр психосоціальної безпеки робочого середовища

Публічний портал і автономний локальний інструмент версії 1.0.

## Початок роботи

1. Відкрийте портал GitHub Pages.
2. Завантажте `downloads/barometr-local-1.0.html`.
3. Відкрийте файл в актуальній версії Chrome або Edge.
4. Створіть проєкт, додайте робочі середовища й періоди, імпортуйте XLSX/CSV з анонімними відповідями E/L та заповніть чекап P.

Локальний інструмент не потребує сервера, не використовує аналітику або телеметрію та не передає дані через інтернет. Сирі відповіді обробляються в пам’яті браузера; у файлі проєкту зберігаються лише агреговані результати, налаштування, чекап P і План дій.

## Методологічні межі

- Джерела E, L і P відображаються окремо; інтегрального бала або загального статусу компанії немає.
- Мінімум для E: 20 відповідей. Мінімум для L: 10 відповідей.
- «Не стосується моєї роботи» виключається зі знаменника.
- Статуси: «Ясно», «Хмарно», «Буря», «Туман».
- Суттєвий розрив E/L: від 20 відсоткових пунктів.

## Склад релізу

- публічний інформаційний портал;
- один автономний HTML-файл;
- фінальний XLSX для створення анкети;
- інструкція для власника дослідження;
- технічна довідка з безпеки даних;
- файл контрольних сум `release-manifest.json`;
- звіт перевірок `QA-RESULTS.md`.
